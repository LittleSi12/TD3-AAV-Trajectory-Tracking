### 3.1 马尔可夫决策过程建模

#### 3.1.1 强化学习基本框架

强化学习（Reinforcement Learning, RL）是机器学习的一个重要分支，研究的是智能体（Agent）如何在与环境（Environment）的交互过程中，通过试错学习到一个最优的行为策略。与监督学习不同，强化学习不需要标注好的"正确答案"作为训练数据，而是通过环境反馈的奖励信号来引导学习方向。

强化学习的基本交互循环如下：在每个时间步 $t$，智能体观察当前环境状态 $s_t$，根据其策略 $\pi$ 选择一个动作 $a_t$，环境接收该动作后转移到新状态 $s_{t+1}$，并返回一个标量奖励信号 $r_t$。智能体的目标是学习一个策略 $\pi$，使得从任意初始状态出发，未来累积奖励的期望值最大化。

这一交互过程的数学基础是马尔可夫决策过程（Markov Decision Process, MDP）。MDP 为序贯决策问题提供了严格的数学框架，是几乎所有强化学习算法的理论基石。

#### 3.1.2 马尔可夫决策过程的形式化定义

马尔可夫决策过程由一个五元组 $(\mathcal{S}, \mathcal{A}, P, R, \gamma)$ 定义，各元素的含义如下：

**状态空间** $\mathcal{S}$：所有可能的环境状态构成的集合。在无人机轨迹跟随问题中，状态包含了无人机的位置、速度、航向以及与目标轨迹的相对关系等信息。状态空间可以是离散的（有限个状态）或连续的（无限个状态）。本文的问题属于连续状态空间，因为无人机的位置和速度都是连续变量。

**动作空间** $\mathcal{A}$：智能体在每个状态下可以选择的所有动作构成的集合。在本文中，动作是无人机的速度和偏航率指令，属于连续动作空间。连续动作空间的处理比离散动作空间更具挑战性，需要专门的算法（如 DDPG、TD3、SAC 等）来处理。

**状态转移函数** $P: \mathcal{S} \times \mathcal{A} \times \mathcal{S} \rightarrow [0, 1]$：描述在状态 $s$ 下执行动作 $a$ 后转移到状态 $s'$ 的概率，即 $P(s'|s, a)$。在本文中，由于采用确定性的运动学模型且不考虑外部扰动，状态转移是确定性的——给定当前状态和动作，下一个状态是唯一确定的。这简化了问题的复杂度，但不影响强化学习算法的适用性。

**奖励函数** $R: \mathcal{S} \times \mathcal{A} \rightarrow \mathbb{R}$：定义智能体在状态 $s$ 下执行动作 $a$ 后获得的即时奖励。奖励函数是强化学习中最关键的设计环节，它编码了任务目标——"什么样的行为是好的"。本文设计了多分项组合奖励函数，将在 3.4 节详细阐述。

**折扣因子** $\gamma \in [0, 1)$：用于平衡即时奖励和未来奖励的相对重要性。$\gamma$ 越接近 1，智能体越重视长远回报；$\gamma$ 越接近 0，智能体越"短视"，只关注眼前的奖励。

#### 3.1.3 马尔可夫性质

MDP 的核心假设是**马尔可夫性质**（Markov Property），也称为"无记忆性"：系统的未来状态只取决于当前状态和当前动作，而与历史状态序列无关。用数学语言表达为：

$$P(s_{t+1} | s_t, a_t, s_{t-1}, a_{t-1}, \ldots, s_0, a_0) = P(s_{t+1} | s_t, a_t)$$

这一性质的直观含义是：当前状态 $s_t$ 已经包含了做出最优决策所需的全部信息，无需回顾历史。对于无人机轨迹跟随问题，马尔可夫性质要求状态表示必须足够充分——不仅包含无人机自身的运动状态，还需要包含与目标轨迹的相对关系信息。如果状态表示不完整（例如只包含位置而不包含速度），则系统不满足马尔可夫性质，强化学习算法的收敛性将受到影响。

本文通过精心设计的 13 维观测向量（包含相对位置、距离、速度、航向误差和前瞻点信息）来满足马尔可夫性质的要求，确保当前观测包含了做出最优跟随决策所需的全部信息。

#### 3.1.4 策略与价值函数

在 MDP 框架下，智能体的行为由**策略**（Policy）$\pi$ 描述。策略是从状态到动作的映射，可以是确定性的 $a = \mu(s)$ 或随机性的 $a \sim \pi(\cdot|s)$。本文采用的 TD3 算法学习的是确定性策略 $\mu_\theta(s)$，其中 $\theta$ 为策略网络的参数。

为评估策略的优劣，定义**状态价值函数**（State Value Function）：

$$V^\pi(s) = \mathbb{E}_\pi\left[\sum_{t=0}^{\infty} \gamma^t r_t \bigg| s_0 = s\right]$$

该函数表示从状态 $s$ 出发，按照策略 $\pi$ 行动，未来所有折扣奖励之和的期望值。价值越高，说明该状态越"有利"。

进一步定义**动作价值函数**（Action Value Function，也称 Q 函数）：

$$Q^\pi(s, a) = \mathbb{E}_\pi\left[\sum_{t=0}^{\infty} \gamma^t r_t \bigg| s_0 = s, a_0 = a\right]$$

Q 函数表示在状态 $s$ 下执行动作 $a$，之后按照策略 $\pi$ 行动的累积折扣回报期望。Q 函数比状态价值函数多了一个动作维度，它直接告诉我们"在某个状态下，哪个动作更好"，是 Actor-Critic 类算法的核心学习对象。

强化学习的最终目标是找到**最优策略** $\pi^*$，使得对所有状态 $s$，其价值函数都取到最大值：

$$\pi^* = \arg\max_\pi V^\pi(s), \quad \forall s \in \mathcal{S}$$

#### 3.1.5 累积折扣回报

智能体的优化目标是最大化从初始状态出发的**累积折扣回报**（Cumulative Discounted Return）：

$$J(\pi) = \mathbb{E}_\pi\left[\sum_{t=0}^{T} \gamma^t r_t\right]$$

其中 $T$ 为 episode 的长度（可以是有限的或无限的），$\gamma = 0.99$ 为折扣因子。

折扣因子 $\gamma = 0.99$ 的选择具有明确的物理含义。在无人机轨迹跟随任务中，一个 episode 的典型长度为 1000~3000 步。$\gamma = 0.99$ 意味着 100 步之后的奖励被折扣为当前的 $0.99^{100} \approx 0.37$（约 37%），1000 步之后的奖励被折扣为 $0.99^{1000} \approx 0.00004$（几乎为零）。这一设置使得智能体既重视长期回报（不会只顾眼前），又不会过度关注遥远未来的奖励（避免训练不稳定）。

较高的折扣因子对于轨迹跟随任务尤为重要：智能体需要学会"提前规划"——例如在接近弯道时提前减速，虽然减速会降低当前步的跟随奖励（因为前进速度变慢），但能避免未来多步的大幅偏离惩罚。只有当 $\gamma$ 足够大时，智能体才有动力做出这种"牺牲当前、换取未来"的决策。

#### 3.1.6 无人机轨迹跟随的 MDP 建模

将上述 MDP 框架具体应用到无人机轨迹跟随问题中，各要素的对应关系如下：

| MDP 要素 | 轨迹跟随问题中的对应 |
|----------|---------------------|
| 智能体 | 无人机控制器 |
| 环境 | 包含目标轨迹的二维仿真世界 |
| 状态 $s$ | 无人机与目标轨迹的相对关系（13 维观测向量） |
| 动作 $a$ | 速度和偏航率指令（2 维连续向量） |
| 状态转移 $P$ | 运动学方程（确定性） |
| 奖励 $R$ | 多分项组合奖励（跟随+航向+平滑+事件） |
| 折扣因子 $\gamma$ | 0.99 |
| Episode 终止 | 完成轨迹 / 飞出边界 / 超时 |

这一建模将连续控制问题转化为标准的 MDP 形式，使得可以直接应用成熟的深度强化学习算法（如 TD3）来求解最优策略。接下来的 3.2~3.4 节将详细阐述状态空间、动作空间和奖励函数的具体设计。
